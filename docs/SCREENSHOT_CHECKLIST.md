## 🛠️ Instructions for Capturing Standard Report Images

1. **Resolution & Scaling:**
   - Capture in full desktop browser resolution (1920 × 1080) at 100% zoom.
   - For mobile layout (Item 18), use Chrome DevTools Device Mode set to iPhone 14 / Pixel 7 (390 × 844 px).
2. **Data Consistency:**
   - Use the pre-seeded demo user (`hero@lifequest.com`) to ensure all charts, heatmaps, badges, and character attributes have populated data.
3. **Format & Naming:**
   - Save all captured screenshots in PNG format under a `screenshots/` directory using standard filenames:
